# Pocket Maze

A small offline Android maze-chase game inspired by classic arcade games.

## Build APK
Open this folder in Android Studio, let Gradle sync, then select **Build → Build APK(s)**. The debug APK is written to `app/build/outputs/apk/debug/app-debug.apk`.

Controls: use the on-screen arrows or tap the left/right half of the maze. Collect dots for points.
